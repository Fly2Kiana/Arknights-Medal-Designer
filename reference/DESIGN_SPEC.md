## 一、明日方舟蚀刻章（已基本还原，微调三项）

| 要素 | 规范 |
|---|---|
| 外形 | 尖角朝上下正六边形，宽高比≈0.866，无挂扣 |
| 边框 | 多层同心细线套环（金章另有内缘星环） |
| 底面 | 哑光平印 + 半调网点 + 细放射密纹；**无镜面高光带** |

## 二、终末地蚀刻章（修正后规范）

| 要素 | 规范 |
|---|---|
| 外形 | 尖角朝上下**正六边形**，实测宽高比 **0.877~0.898**（理论正六边形 0.866，素材仅略变宽，来自外发光/阴影与 3~9° 斜放；**并非纵向拉伸**），六角锐利、无切角 |
| **章内顶部铭牌框** | 顶点下方一枚小矩形名牌框（宽≈章宽 14~18%，深色描边）——终末地识别性特征，方舟没有。**注意：它在六边形轮廓内部，不是外凸挂扣**（实测 h/w ≤ 1.140 < 正六边形理论 1.1547，无任何章越出轮廓） |
| 边框 | 仅 1 条细深色描边（近黑#1E2124/深棕#241A0E），±1 条极细内线；**无套环** |
| 材质 | **阳极氧化拉丝金属反光**：一条上偏左→下偏右的强镜面高光带（亮#F2F2F0），暗部银#3A3D3C/金#6C4E3A，明度跨度≥60；顺向拉丝纹理；下缘/右缘青绿虹移（#6FB8A8/#6E7A3A） |
| 底面 | 光滑金属渐变，无网点、无放射密纹；可叠极淡 HUD 技术纹 |
| 纹章 | 平面 2D 线稿/棱线分面（工程图纸风）：几何机件母题（齿轮罗盘/菱形/立方体/扳手），亮底白线 #F5F5F0 或白底深线 #3A3D3C，可缀 1~2 个小红点 #E23A4A |
| 文字 | **章面极简**：角部小深色 label 印数字（15/20/40）+ 极小 HUD 注记；无横幅字带无大标题（标题/描述/日期在图鉴列表行内） |
| 变体 | ①缎面银白（亮#E9E6E5→暗#B9BBBB，深灰纹章）②镀层金（亮#F7E9AC→暗#6C4E3A，深棕纹章#3B2E1A，铜绿边）③炫彩全息（橙#F5A623→黄绿#C6D94B→青绿#4FC9C0→蓝紫#7C6BD6→粉#E56AA0，白色纹章+黑描边）④隐藏=同构 ⑤未获得=灰色空心槽 |

## 三、两游本质差异一句话

- 方舟 = **哑光平印印张**（网点+套环+字带，平面感）
- 终末地 = **阳极氧化金属反光**（镜面高光带+拉丝+章内铭牌框，立体感）

## 三·五、品阶体系

### 明日方舟：普通蚀刻章 → 镀层蚀刻章

PRTS 维基原文：「部分蚀刻章含有镀层，达成相应条件后可对原蚀刻章镀层（**显示特殊的视觉效果**）」。

对 6 对官方成对素材的逐像素对比结论——
**一定不变（骨骼）**：
- 尖角六边形轮廓、同心套环层数与间距
- 纹章几何、镂空负空间、放射密线结构
- 文字/铭文内容、字号、位置、横幅字带结构

**一定变（镀膜）**：
1. 金属固有色 → 全息虹彩镀膜：冷底章泛青蓝紫绿光谱，暖底章泛金铜
2. 主体纹章与镂空细线边缘叠加虹彩高光（透出粉/青/绿）
3. 整体明度提亮、高饱和底色被柔化（蓝橙/红橙明显褪淡）
4. 高光从单一白点变为多彩漫反射

> 规则本质：**镀层是表面镀膜而非重新设计**——只改渲染不改骨骼。

### 终末地：银色 → 金色 → 特殊镀层（三阶进化）

权威文本（Game8 日维基 + note 实测）：
- 「初期勲章から特定の条件を満たして進化した**加工勲章**…加工することで勲章の**色が変わる**」（满足条件后加工，**颜色改变**）
- 「**改鋳勲章**＝段階強化が複数ある勲章」（部分勋章有多阶段强化）
- note 实测：「限时击杀 Boss → 勲章颜色改变 ＝ 勲章加工」
- B站攻略标题佐证：「全**镀层**徽章蚀刻章」「活动**金镀层**」「3个**炫彩**刻章」

| 阶 | 名称 | 视觉 |
|---|---|---|
| 一阶 | **银色**（初期） | 缎面银白金属 #E9E6E5→#B9BBBB，冷调单色反光，深灰线稿纹章 |
| 二阶 | **金色**（加工） | 暖金铜 #F7E9AC→#8A6A24，暖金反光替代银灰，深棕纹章；骨架不变 |
| 三阶 | **特殊镀层**（炫彩/活动/极秘解锁） | 在金色基础上叠加全息光谱 橙#F5A623→黄绿#C6D94B→青绿#4FC9C0→蓝紫#7C6BD6→粉#E56AA0，白色纹章 |

> 判据：金色阶 = 单一暖金无多色光谱；炫彩阶 = 出现全息多色光谱。三阶是同一章面的渲染递进。

## 七、终末地品阶与形制家族（v2 新增，2026-09-12）

### 7.1 获取与镀层机制（BWIKI 原文）

- 影拓丰碑（常驻高难）："通关任一系列普通模式的全部关卡后，即可获得该系列蚀刻章；
  通关该系列苦难模式的全部关卡后，即可对该系列蚀刻章进行**镀层**。"
- 限时活动："完成全部活动任务 → 获得蚀刻章；限时完成附加挑战 → 镀层。"
- 结论：**每枚章两态**（普通/镀层），镀层=同骨骼强化渲染；与 §三·五 结论互证。

### 7.2 品阶配色（对应成就命名"铜色/银色/金色以此成章"）

| 品阶 | 视觉 |
|---|---|
| 深灰/黑（排名章） | 碳灰金属（章面 9×9 格中位 0.32≈82/255，不是"近黑"）+白蚀刻+`#1/#2/#3` 角标（如"武陵工业先驱"系列） |
| 银（基础阶） | **浅银白金属**（格中位 0.68≈174/255、饱和≈14/255、微冷）+ 浅银/白蚀刻（v3 勘误 2026-09-22：v2 的"战斗银阶实为深灰观感、lum≈80"挂错档，那个数是深灰档的；银档素材本身就是亮银白） |
| 金（进阶阶） | 金拉丝+米白蚀刻，常带计数（20/40/500 TIMES/10000）或桂冠 |
| 镀层（虹彩/珠光） | 白底珠光虹彩（青→粉偏移）+深灰蚀刻（同一章的强化态） |
| 特殊金（剧情/活动） | 金→绿→橙渐变+米白蚀刻+彩色点缀（红/mint/蓝） |

> 上表两个亮度数来自对章面 9×9 格的逐格实测（口径：逐格排除纹章像元后取 rgb 均值、
> 亮度 = max(R,G,B)/255、空格补本组中位，再按「同品阶」分组取中位）；
> 饱和数 = 同批格测中银档（`collection/silver`）的基线饱和 `base_sat[0]`，
> 该字段属采集侧记录、未随本包发布。另有按章面掩膜逐枚取中位的 `base_lum` 口径，
> 与上面的格口径**不是一回事**，两者差 0.03~0.04，不可互抄。

### 7.3 章面版式家族（v3 勘误，2026-09-20 素材全量实测）

> **原 v2 的"5 种章体形制"系误读。** 95 枚章逐张轮廓判定：与尖角正六边形的 IoU 中位数
> 0.956（收藏页）/ 0.973（陈列大图），最小值 0.927，**95/95 判为六边形胜出**；
> 宽高比稳定 0.877~0.898（尖顶正六边形理论值 0.866），无任何一枚出现切角或外凸挂扣。
> 章体一律尖角正六边形，家族差异只发生在**章面内部**的装饰与版式：

| 家族 | 章面差异（六边形轮廓不变） |
|---|---|
| 素章（剧情/活动） | 纯纹章线稿，无附加框件 |
| 计数章（战斗） | 章内顶部铭牌框 + "TIMES" 小字计数 |
| 工业/调度 | 胶囊条 + 圆盘表盘 + 双三角 + 侧边接口触点（均为章面内印元素，非外凸件） |
| 排名/锤炼 | 斜分隔线 + 大数字 + 角标 `#1/#2/#3`（实测 h/w ≤ 1.140，顶部圆孔在章内） |
| 奇想 | 圆形"怀表"盘元素压在章面上 |

**全家族共通识别元素**：角部工程注记（`+001-E-1908` 类）、半调网点、拉丝金属渐变、
底部接口触点/螺丝孔、章内顶部铭牌框。

### 7.4 对引擎的现状差距（供改进排期）

- 引擎章体已统一为尖角正六边形（2026-09-20），v2 所述"单一模板只覆盖形制 2"作废；
  当前缺口在**章面版式层**——五家族的框件/表盘/注记仍由三家族模板近似，未逐族复刻；
- 品阶模板已覆盖 银/金/炫彩/深灰/铜/珠光，但"特殊金"仍缺整章色相直方图判据；
- 镀层虹彩按"全息光谱"实现，与截图中的"白底珠光偏移"观感需对齐（实测珠光饱和带宽
  0.107~0.132，与亮银 0.039~0.071 干净分离，可作为校准锚点）。
