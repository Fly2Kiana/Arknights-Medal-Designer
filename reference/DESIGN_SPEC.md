# 蚀刻章设计规范 v1 · 基于真实素材的考据结论

> 依据样本：明日方舟 PRTS 官方素材 4 张（promo_02/event_02/event_03/event_04）；
> 终末地游戏内 UI 截图（勲章/BADGE 展示面板、荣耀之路列表、勋章陈列厅）与全镀层对比图。
> 规范由公开素材归纳，出处见文内引注。

## 一、明日方舟蚀刻章（已基本还原，微调三项）

| 要素 | 规范 |
|---|---|
| 外形 | 尖角朝上下正六边形，宽高比≈0.866，无挂扣 |
| 边框 | 多层同心细线套环（金章另有内缘星环） |
| 底面 | 哑光平印 + 半调网点 + 细放射密纹；**无镜面高光带** |
| 金章 | 乳白底 + 放射密纹 + 明暗渐层（非平涂珐琅） |
| 镀层 | 全息虹彩**覆盖整枚章面**（非仅轮廓+环带）← 需修正 |
| 纹章 | 扁平线描，银白/深铜金 |
| 文字 | 中央横幅字带 + 大号数字 |

## 二、终末地蚀刻章（修正后规范）

| 要素 | 规范 |
|---|---|
| 外形 | 与方舟同款尖角正六边形，但略纵向拉伸（宽：高≈0.76~0.80，更挺拔），六角锐利 |
| **顶部挂扣** | 顶点中央一枚小矩形挂扣/铭牌框（宽≈章宽14~18%，深色描边）——终末地识别性特征，方舟没有 |
| 边框 | 仅 1 条细深色描边（近黑#1E2124/深棕#241A0E），±1 条极细内线；**无套环** |
| 材质 | **阳极氧化拉丝金属反光**：一条上偏左→下偏右的强镜面高光带（亮#F2F2F0），暗部银#3A3D3C/金#6C4E3A，明度跨度≥60；顺向拉丝纹理；下缘/右缘青绿虹移（#6FB8A8/#6E7A3A） |
| 底面 | 光滑金属渐变，无网点、无放射密纹；可叠极淡 HUD 技术纹 |
| 纹章 | 平面 2D 线稿/棱线分面（工程图纸风）：几何机件母题（齿轮罗盘/菱形/立方体/扳手），亮底白线 #F5F5F0 或白底深线 #3A3D3C，可缀 1~2 个小红点 #E23A4A |
| 文字 | **章面极简**：角部小深色 label 印数字（15/20/40）+ 极小 HUD 注记；无横幅字带无大标题（标题/描述/日期在图鉴列表行内） |
| 变体 | ①缎面银白（亮#E9E6E5→暗#B9BBBB，深灰纹章）②镀层金（亮#F7E9AC→暗#6C4E3A，深棕纹章#3B2E1A，铜绿边）③炫彩全息（橙#F5A623→黄绿#C6D94B→青绿#4FC9C0→蓝紫#7C6BD6→粉#E56AA0，白色纹章+黑描边）④隐藏=同构 ⑤未获得=灰色空心槽 |

## 三、两游本质差异一句话

- 方舟 = **哑光平印印张**（网点+套环+字带，平面感）
- 终末地 = **阳极氧化金属反光**（镜面高光带+拉丝+挂扣，立体感）

## 三·五、品阶体系

### 明日方舟：普通蚀刻章 → 镀层蚀刻章

PRTS 维基原文：「部分蚀刻章含有镀层，达成相应条件后可对原蚀刻章镀层（**显示特殊的视觉效果**）」。

对 6 对官方成对素材的逐像素对比结论——
**一定不变（骨骼）**：
- 尖角六边形轮廓、同心套环层数与间距
- 纹章几何、镂空负空间、放射密线结构
- 文字/铭文内容、字号、位置、横幅字带结构

**一定变（镀膜）**：
1. 金属固有色 → 全息虹彩镀膜：冷底章泛青蓝紫绿光谱，暖底章泛金铜
2. 主体纹章与镂空细线边缘叠加虹彩高光（透出粉/青/绿）
3. 整体明度提亮、高饱和底色被柔化（蓝橙/红橙明显褪淡）
4. 高光从单一白点变为多彩漫反射

> 规则本质：**镀层是表面镀膜而非重新设计**——只改渲染不改骨骼。

### 终末地：银色 → 金色 → 特殊镀层（三阶进化）

权威文本（Game8 日维基 + note 实测）：
- 「初期勲章から特定の条件を満たして進化した**加工勲章**…加工することで勲章の**色が変わる**」（满足条件后加工，**颜色改变**）
- 「**改鋳勲章**＝段階強化が複数ある勲章」（部分勋章有多阶段强化）
- note 实测：「限时击杀 Boss → 勲章颜色改变 ＝ 勲章加工」
- B站攻略标题佐证：「全**镀层**徽章蚀刻章」「活动**金镀层**」「3个**炫彩**刻章」

| 阶 | 名称 | 视觉 |
|---|---|---|
| 一阶 | **银色**（初期） | 缎面银白金属 #E9E6E5→#B9BBBB，冷调单色反光，深灰线稿纹章 |
| 二阶 | **金色**（加工） | 暖金铜 #F7E9AC→#8A6A24，暖金反光替代银灰，深棕纹章；骨架不变 |
| 三阶 | **特殊镀层**（炫彩/活动/极秘解锁） | 在金色基础上叠加全息光谱 橙#F5A623→黄绿#C6D94B→青绿#4FC9C0→蓝紫#7C6BD6→粉#E56AA0，白色纹章 |

> 判据：金色阶 = 单一暖金无多色光谱；炫彩阶 = 出现全息多色光谱。三阶是同一章面的渲染递进。
