# 设计语言说明 · Design Spec

本文说明两种游戏风格蚀刻章的视觉特征，供使用者理解输出效果、供贡献者保持风格一致。
内容为风格描述，不含官方美术资源；所有输出均为风格演绎的玩家二创。

## 总体形制

- 章体为**正六边形**（尖角朝上），边缘锐利、无切角。
- 章面承载蚀刻纹章（由输入照片转译而来），配铭文或角部注记。
- 金属质感通过明暗排线、网点或拉丝反光表现，而非平滑照片渐变。

## 明日方舟风格（哑光金属）

- 哑光金属底 + 细密网点 + 放射密纹；纹章以扁平蚀刻线描呈现。
- 多层同心细线套环勾勒边缘；中央横幅字带 + 大号数字。
- 品阶：`silver`（银）、`plated`（镀层，虹彩覆盖章面）、`gold`（金，乳白底放射密纹）、`stamp`（朱砂印）。
- 识别特征：同心套环 + 网点底 + 字带，无名牌框。
- 镀层是"表面镀膜而非重新设计"：轮廓、套环、纹章几何与铭文不变，只叠加虹彩镀膜并提亮。

## 终末地风格（阳极氧化金属）

- 阳极氧化拉丝金属，带一条方向性镜面高光带；章面光滑渐变、无网点。
- 章内顶部一枚小矩形名牌框（识别性特征，位于六边形轮廓内部）；仅单条细描边、无套环。
- 纹章为工程图纸风的几何机件母题（齿轮 / 罗盘 / 菱形 / 立方体），章面极简、角部小注记。
- 品阶：`silver`（缎面银白）、`gold_pure`（纯金）、`gold_plated`（镀彩金，多色光谱）、`dark`（深灰）、`bronze`（铜）、`pearl`（珠光虹彩）。
- 形制家族：`story`（陈列章，名牌 + 角部注记 + 底部接口）、`combat`（计数章，吊环 + 计数铭文）、`industry`（工业章，表盘 + 侧边接口）。
- 品阶递进：银 → 金 → 特殊镀层，是同一章面的渲染递进（骨骼不变、颜色与镀膜变化）。

## 糖果贴纸风格

- 高饱和贴纸观感、圆润边缘，适合轻松题材。

## 两游差异一句话

- 方舟 = 哑光平印印张（网点 + 套环 + 字带，平面感）。
- 终末地 = 阳极氧化金属反光（镜面高光带 + 拉丝 + 章内名牌框，立体感）。

## 风格边界

- 引擎把输入「转译」为风格化纹章，不逐字临摹官方美术。
- 色彩与形制以游戏内观感为参照、通过采样参考素材定标，保持各档之间清晰可辨。
