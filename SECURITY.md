# Security policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is enabled for the repository. If it is unavailable, open a minimal issue asking for a private contact channel without including exploit details.

Do not paste credentials, private paths, personal photos, or session content into an issue or attachment.

## Scope notes

This is a local image-generation tool. It reads local images and writes local PNGs; it does not host services, store credentials, or transmit user photos (the web tool performs all processing in the browser). Reports are expected to concern local processing, dependency versions, or documentation.
