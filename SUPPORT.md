# Support

Start with the [README](README.md), the [operator manual](PROMPTS.md), and the [known boundaries](README.md#known-boundaries) section.

For a reproducible bug, open an issue with: Python version, `pip freeze` for numpy/Pillow, the input category (photo/graphic), the exact command line, and the observed vs. expected output. Prefer the bundled `samples/` images; do not attach personal photos.

For vulnerabilities, follow the instructions in [SECURITY.md](SECURITY.md). Do not disclose exploit details or secrets in a public issue.
