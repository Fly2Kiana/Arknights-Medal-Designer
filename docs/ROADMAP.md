# 路线图 · Roadmap

方舟蚀刻章设计器今天已是一个可用工具：通过引擎、网页工具、命令行与 AI agent skill，把照片做成明日方舟 / 终末地风格的蚀刻章。本页概述项目的发展方向，均为计划方向，非发布承诺。

## 近期

- **跨平台字体**：当前使用 Windows 系统字体；计划为 macOS 与 Linux 提供优雅的字体回退，让铭文在各平台一致呈现。
- **更多章种**：扩充两种游戏风格下的章面版式与品阶覆盖。

## 远期

- **更丰富的纹章设计**：为 AI 纹章设计路径增加更多装饰元素与布局族。
- **更顺滑的迭代**：通过会话归档，让「在上一次那张上改一处」更省事。
- **各入口体验一致**：网页工具与引擎随演进保持同步。

## 原则

- **本地优先**：照片处理留在本机；任何云端视觉 API 均为可选、由你自行配置。
- **仅限二创**：输出为风格演绎，供个人娱乐，绝非官方素材。
- **忠于风格**：每个品阶保持清晰可辨、贴合游戏观感。
