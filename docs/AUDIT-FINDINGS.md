# 安全与隐私实践

本页概述方舟蚀刻章设计器在安全与隐私上的做法。报告漏洞见 [SECURITY.md](../SECURITY.md)。

## 默认本地

- 照片在本机处理。引擎读取本地图片、写出本地 PNG；不托管服务、不存储凭据。
- 网页工具完全在浏览器内运行。其 AI 抠图模型随仓库分发（`web/vendor/`）并按 SHA-256 校验；版本锁定的公共 CDN 仅作回退。照片数据不离开浏览器。

## 唯一可选的联网路径

- 可选的 `engine/design_emblem.py` 适配器会把照片压缩后发送到**你自行配置**的视觉 API 端点（默认 `api.openai.com`），并使用环境变量中的 API 密钥。请仅对可信端点使用。
- 明文 `http://` 端点会被拒绝，回环地址除外——以便使用全本地模型。

## 输入与依赖加固

- 超大输入会被直接拒绝（解压炸弹防护）；网页工具在处理前先降采样大图。
- 视觉 API 返回的设计稿 JSON 在渲染前先校验。
- 运行期依赖极简（numpy + Pillow）；CI 动作按提交 SHA 固定。
- 无遥测、无硬编码凭据，不对不可信输入使用 `eval` / `exec` / `pickle`。
