# 变化与批量 · Variations & Batches

同一张照片可以变成多枚不同的章。本页说明变化如何产生，便于你得到一组互不相同的结果，而非近乎重复。

## 设计之间变什么

- **母题转译**：正面纹章像、标志物剪影、或特征符号拼合。
- **布局**：中央对称 + 双翼、X 交叉 + 底部字带、或环带包围放射星芒。
- **装饰**：月桂、放射星芒、缎带或星形环阵。
- **明度侧重**：亮面居中暗线包边，或暗面居中亮线勾边。
- **品阶极性**：浅底深线或深底白线，不改构图。

## 得到好的变化范围

- 质量不稳时，先出几个互不相同的概念，选优者渲染。
- 批量出图时，相邻两枚在上述维度中至少有两处不同，让一组看起来多样而非重复。
- 构图拥挤时先删次级装饰——主母题与风格识别特征保持不变。

变化由纹章设计驱动，命令行与 AI agent skill 都能产出。用法见 [PROMPTS.md](../PROMPTS.md)。
