# 质检门禁 · Quality Gate（references/quality-gate.md）

> 出图后**必须**逐项判定 PASS/FAIL 再交付（自带视觉则自读图，否则委派任意可用视觉模型）。
> 未过线条目 = 返工指令：改设计稿（prompt-compiler）或改参数重跑，最多 2 轮；
> 2 轮仍不过 → 如实说明边界后交付，不得声称达标。

## A. 章体结构（固定系统，FAIL 即硬伤）

- [ ] G1 六边形为正六边形（方舟宽高比 0.866±1%；终末地纵向拉伸比例正确），顶点合拢无空隙
- [ ] G2 游戏识别特征正确：方舟=套环+网点+字带+无挂扣；终末地=挂扣+单描边+镜面高光带+章面极简
- [ ] G3 明度纪律：纹章区无平滑渐变，三档硬明度可辨
- [ ] G4 外沿裁切干净，六边形外无杂散像素/网点残留

## B. 主体纹章

- [ ] G5 读起来是"设计过的纹章"，不是"处理过的照片"（转译原则）
- [ ] G6 主母题占 55–65%，无孤立碎块、无大面积空洞
- [ ] G7 保留等级达标：high 保留的可辨识特征（脸型/发色/武器形态/毛色分区）在章上可认出
- [ ] G8 游戏关联：游戏相关输入有角色/物件标志符号母题，无泛化简笔画

## C. 文字

- [ ] G9 主铭文精确居中（偏差 ≤1px）、无溢出字带/气泡、无错字乱码
- [ ] G10 字体符合：金属风=Bahnschrift/雅黑粗体；糖果风=圆体+字距跟踪

## D. 图层与冲突

- [ ] G11 名字气泡/字带不与边框环、装饰、主体重叠（穿模=FAIL）
- [ ] G12 装饰全部在章内，收口外环完整

## E. 质感

- [ ] G13 糖果风：白胶边+三色环+缝线+贴纸凸起齐备；金属风：网点/颗粒/偏光齐备
- [ ] G14 品阶正确：金章无全息光谱、镀层/炫彩有光谱且不糊满（≤面 30% 或仅随形附着）

## 交付契约（Generate 模式输出必须包含）

1. 最终 PNG 路径（stderr 告警如实转告，例如"低置信整图回退"）
2. 所用设计稿 JSON（或声明走的离线兜底模式）
3. 模式/风格/品阶/极性/保留等级一行说明
4. 质检结论：全部 PASS，或如实列出未过项与轮次

## 验收基准（视觉评审 0–1）

糖果 ≥0.85 / 金属 ≥0.85 / 游戏关联 ≥0.7 可交付；任一 A 类 FAIL 直接不可交付。
