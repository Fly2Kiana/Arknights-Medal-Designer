# 风格系统 · Style System（references/style-system.md）

> 设计语言考据结论的「固定/可变」分解，依据 `reference/DESIGN_SPEC.md`（PRTS 官方素材与
> 游戏内 UI 归纳）与引擎常量（`engine/badge_engine.py` PALETTES/FIELD_COLORS）。
> 用途：设计纹章与质检时判定"什么是必须保持的家族特征，什么是允许变化的创作空间"。

## 一、固定系统（fixed——破坏即不像）

### 共同骨架
- 尖角正六边形（pointy-top）：方舟宽高比 ≈0.866；终末地略纵向拉伸 ≈0.76–0.80，六角锐利
- 三档硬明度：**0.22（暗线）/ 0.55（中调）/ 0.88（亮面）**，禁止平滑渐变替代
- 主母题占章面中央 55–65%，对称或 X 形中心对称构图
- 「转译不临摹」：提取 1–2 个标志性特征重构成纹章母题，不是照片滤镜

### 明日方舟（哑光平印印张）
- 多层同心细线套环（金章另有内缘星环）；**无挂扣、无镜面高光带**
- 哑光底 + 半调网点 + 细放射密纹；纹章为扁平线描（银白/深铜金）
- 嵌入式横幅字带 + 大号数字（章面有字）

### 终末地（阳极氧化金属反光）
- **顶部矩形挂扣**（识别特征，方舟没有）；仅 1 条细深描边 ±1 极细内线，无套环
- 镜面高光带（明度跨度 ≥60）+ 顺向拉丝；下缘/右缘青绿虹移（#6FB8A8/#6E7A3A）
- 章面极简：角部小数字 label + 极小 HUD 注记，**无横幅字带**

### 色板（引擎实测值，设计稿可引用）
- 方舟 silver/plated：冷灰蓝底 + 银白线；gold：乳白珐琅底 + 深铜金线；stamp：朱砂纸面
- 终末地 ef_silver #E9E6E5→#B9BBBB 深灰线；ef_gold #F7E9AC→#8A6A24 深棕线；ef_irid 白线 + 黑描边 + 全息光谱（橙#F5A623→黄绿#C6D94B→青绿#4FC9C0→蓝紫#7C6BD6→粉#E56AA0）

## 二、可变系统（variable——创作空间）

- 母题选择与转译角度（同一主体可有多种符号化方案）
- 装饰原语组合：bezier/laurel/sunburst/star/banner（渲染器支持的全部 10 种图元见 PROMPTS.md §二）
- 糖果贴纸风的底纹（径向/波点）、粉彩色场、装饰主次
- 明度在硬档内的分布设计（哪里 0.22 哪里 0.88）

## 三、残留（sample residue——禁止带入新设计）

- 官方素材中的具体角色形象、专有名词、日期、活动标识
- 参考图的文字、水印、签名、构图
- 二创边界：输出为风格演绎，不复制官方美术资产（NOTICE 商标声明）

## 四、品阶递进规则（改渲染不改骨骼）

- 方舟「普通→镀层」：六边形/套环/纹章几何/文字**不变**，仅叠加全息镀膜、提亮、柔化
- 终末地「银→金→炫彩」三阶：**同一章面的渲染递进**——金=单一暖金无多色光谱；
  炫彩=出现全息多色光谱
