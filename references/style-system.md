# 风格系统 · Style System

方舟蚀刻章设计器以一组可辨识的游戏风格渲染蚀刻章。本页描述其视觉语言，让你了解每种风格的样子、以及各品阶之间保持一致的部分。完整设计说明见 [DESIGN_SPEC.md](../reference/DESIGN_SPEC.md)。

## 共同形制

- 每枚章都是尖角朝上的正六边形，棱角锐利。
- 章面承载由照片转译而来的蚀刻纹章，配铭文或角部小注记。
- 金属质感通过蚀刻排线、半调网点或拉丝反光表现，而非平滑的照片渐变。

## 明日方舟 — 哑光金属

- 哑光金属底 + 细密半调网点 + 放射密纹；纹章为扁平蚀刻线描。
- 多层同心细线套环勾勒边缘；中央横幅字带承载铭文与大号数字。
- 品阶：`silver`（银）、`plated`（镀层，虹彩覆盖整面）、`gold`（金，乳白珐琅底放射密纹）、`stamp`（朱砂印）。
- 镀层是表面镀膜而非重新设计：形制、套环、纹章与文字不变，只叠加虹彩镀膜并提亮。

## 终末地 — 阳极氧化金属

- 阳极氧化拉丝金属，带方向性镜面高光；章面光滑、无网点。
- 章内顶部一枚小矩形名牌框（识别性特征）；仅单条细描边、无套环。
- 纹章为工程图纸风的几何母题——齿轮、罗盘、菱形、立方体；章面极简，配角部小注记。
- 品阶：`silver`、`gold_pure`、`gold_plated`（多色光谱）、`dark`、`bronze`、`pearl`（珠光虹彩）。
- 形制家族：`story`（陈列章）、`combat`（计数章）、`industry`（工业章）。
- 品阶递进：银 → 金 → 特殊镀层，是同一章面的渲染递进，形制不变。

## 糖果贴纸

- 高饱和、圆润的贴纸观感：白胶边、粉彩底、三色环、缝线与名字气泡，适合轻松题材。

## 固定与可变

- **固定**：六边形形制、各风格的识别特征、纹章与文字结构。
- **可变**：纹章母题、装饰元素与品阶——同一张照片可产出多枚互不相同的章。
