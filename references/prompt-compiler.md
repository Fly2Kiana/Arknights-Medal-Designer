# 纹章设计管线 · Emblem Design Pipeline

本页从高层说明照片如何变成章面纹章。使用工具无需读它——引擎、网页工具与命令行会替你跑完整管线。这里供你了解 AI 纹章设计主路径的工作方式。

## 两条路径

- **AI 纹章设计（主路径）**：视觉模型看你的照片，设计一枚纹章——一组捕捉主体标志性特征的几何图形。引擎把设计渲染上章面，产出「设计过的纹章」而非「处理过的照片」。
- **经典离线兜底**：无视觉模型时，引擎用内置算法直接蚀刻主体（`line`、`silhouette`、`facet`、`icon`）。无需网络、无需模型。

## 设计原则

- **转译不临摹**：纹章把主体的一两个标志性特征——剪影、特征形状、标志配色——抽象成纹章母题，不是照片的复制。
- **均衡构图**：母题居中，由月桂、放射星芒、星形、缎带等装饰元素环绕。
- **有限明度**：蚀刻暗线、中调与亮面保持蚀刻金属观感，而非平滑渐变。
- **游戏关联母题**：游戏相关主体的纹章取自角色或物件的标志符号，而非泛化图形。

## 从设计到章

设计存为一个由几何图元构成的小 JSON 文件，交给引擎合成整枚章——底面、套环、纹章、铭文与品阶。用法与参数见 [PROMPTS.md](../PROMPTS.md)，好结果的标准见 [quality-gate.md](quality-gate.md)。
